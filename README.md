# Multiplayer Shuttle Dock Patch

A RimWorld multiplayer compatibility patch for Shuttle Dock.

This mod uses [RimWorld Multiplayer](https://github.com/rwmt/Multiplayer) to synchronize Shuttle Dock-related data and behavior between multiplayer clients.

## Features

- Adds multiplayer support for Shuttle Dock.

## Requirements

- RimWorld
- [RimWorld Multiplayer - GitHub](https://github.com/rwmt/Multiplayer) or [RimWorld Multiplayer - Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=2606448745)
- [Shuttle Dock](https://steamcommunity.com/workshop/filedetails/?id=3648642429)

## Installation

### Steam Workshop

Subscribe to the required mods and add them to your RimWorld mod list in the following order:

1. Harmony
2. Core
3. Royalty, Ideology, Biotech, and Anomaly, if applicable
4. Multiplayer
5. Shuttle Dock
6. [Multiplayer Shuttle Dock Patch](https://github.com/Keullaeseu/Multiplayer-Shuttle-Dock-Patch/releases/latest)

The patch should load after both RimWorld Multiplayer and Shuttle Dock.

### Manual Installation

1. Download zip from [Releases](https://github.com/Keullaeseu/Multiplayer-Shuttle-Dock-Patch/releases/latest) section.
2. Place the mod folder in your RimWorld `Mods` directory.
3. Enable the required mods in the RimWorld mod manager.
4. Load the mods in the recommended order listed above.
5. Ensure every multiplayer player has the same mod list, configs and load order.

## Multiplayer Usage

All players should have the following mods installed and enabled:

- RimWorld Multiplayer
- Shuttle Dock
- Multiplayer Shuttle Dock Patch

The host and all connected clients must use compatible versions of the game, RimWorld Multiplayer, Shuttle Dock, and this patch.

## Compatibility

This mod is intended to provide multiplayer synchronization for Shuttle Dock. It does not replace either RimWorld Multiplayer or Shuttle Dock.

If you encounter desynchronization issues:

1. Verify that all players use the same mod versions.
2. Check that the load order is identical for everyone.
3. Confirm that the patch loads after RimWorld Multiplayer and Shuttle Dock.
4. Check the multiplayer log for errors.
5. Reproduce the issue with only the required mods enabled, if possible.

## Known Limitations

- Compatibility may be affected by future updates to RimWorld Multiplayer or Shuttle Dock.
- Other mods that modify Shuttle Dock or shuttle behavior may require additional compatibility patches.
